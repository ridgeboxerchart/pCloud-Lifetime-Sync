## Features

- **Cross-Platform Sync Automation** – Templates for seamless file synchronization across Windows, macOS, Linux, iOS, and Android devices[reference:0]
- **Virtual Drive Integration** – Presets for pCloud Drive, enabling cloud storage to appear as a local hard drive with no file size or speed limits[reference:1]
- **Automated Backup Workflows** – Scripts for one-click backup of photos, videos, and documents from any device, plus automatic photo/video upload from mobile devices[reference:2]
- **AI-Powered File Management** – Configurations for connecting pCloud with AI services for file summarization, translation, and image recognition[reference:3][reference:4]
- **Semantic Photo Search** – Workflows for self-hosted semantic image search over WebDAV using OpenCLIP embeddings and vector databases[reference:5]
- **Military-Grade Encryption** – Presets for pCloud Encryption with client-side, zero-knowledge AES-256 encryption where only you hold the keys[reference:6][reference:7]
- **File Versioning & Recovery** – Templates for accessing and restoring previous versions of files, with extended version history capabilities[reference:8]
- **Secure File Sharing** – Configurations for sharing large files with password protection, expiration dates, and direct links[reference:9][reference:10]
- **Offline Access & Media Playback** – Presets for making files available offline and using built-in audio/video players[reference:11][reference:12]
- **Cross-Platform Compatibility** – Configuration scripts for seamless workflow across Windows, macOS, Linux, iOS, and Android[reference:13]

## Usage

1. Download and extract the repository files.
2. Open the `/docs` folder and read the `GettingStarted.md` guide.
3. Choose your desired configuration:
   - **Templates:** Import the automation and folder structure templates from `/templates`.
   - **Scripts:** Run the backup and sync automation scripts from `/scripts`.
   - **Presets:** Apply the AI integration, encryption, and sharing presets from `/presets`.
4. Launch pCloud and follow the documentation to apply your configurations.
